## Responsive verification
- Mobile (390×844) dashboard: `scrollWidth == clientWidth` (390) → **no horizontal overflow**.
- Sidebar collapses below `md`; content remains single-column and reachable.
- Mobile dashboard axe scan: 0 violations.

## Remediation performed
1. **Color contrast (serious):** raised muted text tokens `text-slate-500/600` → `text-slate-400` across 12 view/component files (≥4.5:1 on the dark surfaces).
2. **Pending status badge:** `text-amber-300` on a translucent amber background combined with `animate-pulse` dropped effective contrast to ~4.15:1. Fixed by using `text-amber-200` on `bg-amber-500/20 border-amber-500/40` and moving the pulse animation to the status dot only (text no longer animates opacity). Paused badge similarly moved to `text-purple-200`.

## Accessibility features in place
- Visible focus rings (`focus:ring-2 focus:ring-indigo-500`) on interactive controls.
- Semantic headings, labels tied to inputs, keyboard-activatable buttons/rows.
- Persistent, high-contrast "AUTH STUB — NOT PRODUCTION" banner.
- Monospaced hash digests with copy-to-clipboard and full value in `title`.
